aum · multi-arm uplift with cost and capacity

Which action, for which customer, within which limits?

aum estimates the effect of every possible action on every unit, turns those effects into one decision per unit under real costs and capacities, and then checks honestly whether the decisions beat simple rules. Two case studies show it at work. The beer study runs the whole library workflow end to end on simulated data, where the true answer is known. The loan reminder study uses it to explore real experiments: which treatment wins, in which segments, and which treatments can be dropped so the next pilot tests only real contenders.

    Design choices

    Built to say no when the evidence is thin

    One effect model per arm, shared nuisancesWell-understood binary meta-learners (DR, X, S, T, R), each arm inspectable alone, all learners compared on identical folds.
    Doubly robust scores everywhereLearning, evaluation, calibration and checks use the same scores, unbiased if either the outcome or the propensity model is right.
    A referee grades the modelPolicies are valued with scores fitted on held-out units only. A model graded on its own predictions always looks good.
    Splits by unit, not by rowThe same outlet or customer appears every cycle; row-level splits leak.
    No evidence, no decisionAn arm with a propensity below 0.02 for a unit is never chosen for it.
    Simplest tied candidate winsAmong tuning candidates statistically tied with the best, the simplest is chosen. The top score among many noisy ones is partly luck.

    Beer trade actions

    This study walks through every step of the library above, in order, and publishes the executed notebook and two reports. Each month a brand gives each outlet one action. The outcome is cases ordered; money is gross margin of the extra cases (60,000 VND per case) minus the action's cost. Because the data is simulated, every recommendation can be checked against the true best action.

    • The limits are the largest lever.Without caps the model would earn about 110,000 VND more per outlet-month than within them, about 2,200 million VND per month across all outlets.
    • Within today's limits the data cannot yet show a gain.The simulation knows the capped model earns 58,987 VND more per outlet-month than the current rule. A real project would only see the estimate: 6,070 VND, range −63,936 to 72,631.
    • So the recommendation is a pilot, with its power stated.3 months, random halves of about 9,000 outlets. It detects the simulated gain only about 60 times in 100, so the decision uses a switch rule set in advance.

    Exploration · real experiments · masked results

    Payment reminders before the due date

    A lender tested reminder plans in two randomized experiments. The goal was not a targeting model but a clean shortlist for the next pilot: find the superior plan, find the segments where it is superior, and remove any plan that loses to another in every segment. Each experiment was modelled twice: a full version with every plan, then a reduced version without the dominated ones. The target is an instalment paid on or before the due date.

    The company, country, currency, dates, internal names, customer counts and absolute payment rates are removed. Arms, features and products have generic names, and effects are rounded to 0.1 percentage points.

    • First instalment: one plan wins everywhere.Late schedule with a tracked message first beats every other arm in every product and customer group: +1.0 pp over the early-schedule control, +0.7 pp over the direct-call version.
    • Later instalments: the second reminder is what matters.Two reminders add +1.3 to +1.4 pp over one. Email adds nothing once there are two.
    • Personalising arms adds almost nothing here.In all four versions the model's per-customer policy lands within 0.1 pp of giving everyone the best single arm, and most tuning candidates are statistically tied.
    • Calibration decides which segment differences to believe.First-instalment models draw smooth effect curves but cannot rank customers (slopes include 0). Later-instalment models rank well (slopes 0.6 to 0.9), so their segment splits can guide the pilot.

    What the method is really for

    Beat the best single arm, not only control.In three of the four lending versions the model beats control by 0.7 to 1.4 pp, which sounds like a model win. Against the best single arm the gain is zero. The baseline you compare with decides the story.
    Say how much a test can detect.The beer pilot would miss a real gain 4 times in 10. Stating that up front changes how the result is read.
    Constraints often matter more than the model.In the beer case the caps on display kits and rep visits cost more than any modelling choice. Valuing them gives the business a case for capacity.
    Prune before you pilot.Effects by segment show which treatments lose everywhere. Dropping them leaves a pilot with fewer arms, more customers per arm and a sharper question: 9 plans became 3 in the lending study.
